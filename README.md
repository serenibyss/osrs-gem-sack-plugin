# Gem Sack

A plugin adding overlay text and stored gems tooltips to all 5 of the gem bags:
- Gem Pouch
- Gem Satchel
- Gem Tote
- Gem Bag
- Gem Sack

Each gem-carrying item has configs individually both for the overlay text as well as the tooltip text.
Let me know of any other configuration options that would be desired and I'd be happy to add them!

There may be some issues, as the method of making this work is mostly based on chat and menu interactions,
so it's possible the state gets desynced. If you ever notice a way that is causing this, let me know
and I will try my best to address it.
